# LINE登録特典「AIでできることチェックリスト」

大阪梅田校の公式LINEに登録した人に送るPDF。LPの4本（経営者・個人事業主／サロン／飲食店／会社員）に1種ずつ対応する。
要件定義 Q6（梅田校オリジナル・対象別4種・代表が減らした時間つき）で決めたもの。作成 2026-11-08。

## ファイル

| ファイル | 対応するLP |
|---|---|
| `AIでできることチェックリスト_経営者・個人事業主版.pdf` | `/owner/` |
| `AIでできることチェックリスト_サロン版.pdf` | `/salon/` |
| `AIでできることチェックリスト_飲食店版.pdf` | `/restaurant/` |
| `AIでできることチェックリスト_会社員版.pdf` | `/office/` |

どれもA4・3ページ・約450KB。スマホで見ても、印刷して書き込んでも使える。

## 中身（4種共通の流れ）

1. **チェックリスト**：対象によくある作業16個を4つのグループに分けて並べた。各行に「AIがやること」のひとこと、代表の実例（測った時間）または「代表もAIで運用中」の印、自分の時間を書く欄
2. **リストにない作業**を書き出す欄（2行）と、**AIで仕組みにしやすい作業の見分け方**（4つ）
3. **数えてみましょう**：✓の数・◎（いちばん減らしたい作業）・時間の合計・時給換算・時間ができたらやりたいこと
4. **代表の実例**：合計（約32〜33時間 → 約4時間50分）と主な5つ＋その他。並び順はLPの各版と同じ。代表の吹き出し（関西弁）はLPと同じ一言
5. **LINEで送ってください**：「✓は◯個、◎は◯◯でした」と送ってもらい、講師が「あなたの場合、AIで何が作れそうか」を返す → 無料説明会・個別相談へ
6. 講座と教室の案内、注記

## 表現で気をつけたこと

- 代表の実例の印は、代表が実際に測った11業務だけにつけた。項目名と代表の業務名が違うときは、代表の業務名も書いた（例：「入金の確認と消し込み」→ 代表の実例｜債権チェック）
- 時間を測っていない業務は「代表もAIで運用中」とだけ書き、時間は出していない
- 飲食店版には「代表は飲食店ではなくネイルサロンの経営者」、会社員版には「代表の実例はサロンの事務での数字」と注記した
- 注記：代表の実例であること・結果は人によって異なること・AI利用後の時間には確認と承認の時間も含むこと
- 相談の案内には「ご相談だけでも大丈夫です。講座のご案内は、聞きたい方にだけお伝えします」を入れる（11/14 本人：「受講のご案内もします」は営業されそうで相談しづらいので、個別相談は「講座のご案内は、聞きたい方にだけお伝えします」、説明会は「料金とお申込みの流れもお話ししますが、聞くだけで大丈夫です」に変更）
- 料金と開催日は書かず、「LINEと無料説明会でご案内」にした（PDFは配ったあとに直せないため。LPには料金を載せている）

## 直し方

- 文章：`src/content.mjs`（4種の項目・まえがき・LINEでの送り方の例など）
- 見た目：`src/gift.css`
- 代表の時間：LPと同じ `../site/src/content/common.mjs`（主な5つ・合計・その他）と、`src/content.mjs` の `repTimes`（残りの6業務）
- 教室の住所・アクセス：LPと同じ `../site/src/config.json`

直したら、PDFを書き出し直す。

```bash
node build.mjs
```

1種だけなら `node build.mjs salon`（`owner` / `salon` / `restaurant` / `office`）。
Microsoft Edgeを画面なしで動かしてPDFにする。フォントはネットから読むので、ネットにつながった状態で実行する。PDFを開いたままだと保存できないので、閉じてから実行する。

## LINEで渡すとき（11/8 本人決定）

- **PDFはLINE登録特典として、LINEでだけURLを送る**。LPからはリンクしない
- 公式LINEのメッセージにPDFは直接つけられないので、LPのサイトに置いたPDFのURLを送る。LPを書き出すと（`../site` で `node build.mjs`）、4種のPDFが次の場所にコピーされる
  - `https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-owner.pdf`（経営者・個人事業主版）
  - `https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-salon.pdf`（サロン版）
  - `https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-restaurant.pdf`（飲食店版）
  - `https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-office.pdf`（会社員版）
- ドメインは miraicamp-osaka-umeda.jp（11/8取得）。4種のURLとも開ける状態（11/8確認）
- フォルダ名の `gift-outhlply` は推測されにくいようにランダムな文字を入れたもの（`site/src/config.json` の `giftDir`）。**一度LINEで送り始めたら変えない**（送ったURLが開けなくなる）。検索エンジンに見つからないよう、LP・robots.txt・サイトマップのどこにも書いていない
- ただし、URLを知った人が転送すれば誰でも開ける（LINEの特典はどれも同じ仕組み）
- **公式LINEは本部が作成する（11/8 本人）**。あいさつメッセージに特典のURLを入れられるか、梅田校が文面を決められるかは本部に確認する（公開前チェックリスト A8）

### 文面の案（本部に確認してから使う）

**あいさつメッセージに足す吹き出し**（4種のリンクを並べて、自分に近いものを開いてもらう。あいさつメッセージは1種類しか設定できないため）

```
【ご登録の特典】
AIでできることチェックリスト（PDF・3ページ）

お仕事に近いものを開いてください。
▼経営者・個人事業主の方
https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-owner.pdf
▼サロンオーナーの方
https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-salon.pdf
▼飲食店オーナーの方
https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-restaurant.pdf
▼会社員の方
https://miraicamp-osaka-umeda.jp/gift-outhlply/checklist-office.pdf

当てはまる作業に✓をつけて、
「✓は◯個、◎は◯◯でした」とこのトークで送ってください。
講師から、あなたの場合にAIで何が作れそうかをお返事します。
```

**チェックリストの回答へのお返事（講師が手で送る定型文）**

```
（表示名）さん、送ってくださってありがとうございます！
大阪梅田校の【講師名】です。

✓が【◯個】、◎は「【作業名】」ですね。
「【作業名】」なら、【AIがやること（チェックリストの説明文）】ような道具を、
2日間の講座の2日目に作るテーマにできそうです。

あなたのお仕事の場合に何が作れるかは、
無料説明会・個別相談（オンライン約30分）で具体的にお話しします。
ご相談だけでも大丈夫です。講座のご案内は、聞きたい方にだけお伝えします。
ご希望の方は、メニューの「個別相談を予約」からどうぞ。
```

- 「作れます」「完成します」と言い切らない（「テーマにできそうです」まで）
- 代表の実例の時間に触れるときは「代表の場合は」をつける
